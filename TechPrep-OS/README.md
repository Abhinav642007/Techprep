## 🌟 Overview

**TechPrep OS** is an opinionated, high-performance productivity dashboard created to eliminate friction in interview preparation and software engineering career growth. 

Unlike bloated multi-tool systems or generic habit apps, TechPrep OS unifies everything a developer needs into a single unified workspace:
- **No fake starter progress** — You begin with preloaded curriculums and zero completed tasks, tracking your true real-world effort.
- **100% Client-Side Privacy** — All your logs, notes, streaks, and applications remain safely in your browser's local storage.
- **Zero Build Step / Zero Overhead** — Crafted with vanilla HTML5, custom modular CSS3 design tokens, and lightweight vanilla JavaScript.

## 🚀 Key Features

### 1. Today Focus View
- **Daily Checklist**: Track essential habits (DSA, Development, AI/ML, English Speaking, Reading, Technical Interviews, Workout, Deep Work, etc.).
- **Study / Deep Work Logger**: Log exact study hours with focus area notes and real-time total updates.
- **Real-Time Streak & DSA Counter**: Quick stat badges in the header keep your consistency top-of-mind.
- **Date Navigation**: Easily jump backward or forward to review or backfill daily progress.

### 2. Monthly Habit Matrix (Spreadsheet)
- Full **31-day visual spreadsheet grid** inspired by Excel and Notion habit trackers.
- Color-coded daily completion cells with interactive toggling.
- Real-time monthly completion percentages computed per habit.
- Ability to add custom habits with personalized category tags and icons.

### 3. DSA Problem Tracker
- **21 Curated DSA Topics**: Arrays, Strings, Hashing, Two Pointers, Sliding Window, Binary Search, Linked List, Stack, Queue, Recursion, Backtracking, Trees, BST, Heap, Graphs, Greedy, Dynamic Programming, Tries, Intervals, Bit Manipulation, and Math.
- **Problem Log System**: Log problem title, topic, difficulty (`Easy`, `Medium`, `Hard`), completion date, and key takeaways/notes.
- **Topic-Level Analytics**: See your problem distribution and solve ratios at a glance.

### 4. Full-Stack Development Roadmap
- Comprehensive checklist covering full-stack engineering domains:
  - **Programming**: Java, Python, Object-Oriented Programming (OOP)
  - **Frontend**: HTML5, CSS3, JavaScript, TypeScript, React
  - **Backend**: Spring Boot, REST APIs, Spring Security, JPA / Hibernate, Microservices
  - **Database**: SQL, PostgreSQL, Database Design, Redis
  - **DevOps & Tools**: Git, GitHub, Docker
  - **Cloud**: AWS & Cloud Fundamentals
  - **System Design**: Low-Level Design (LLD) & High-Level Design (HLD)

### 5. AI & Machine Learning Track
- 34 structured topics spanning beginner to cutting-edge AI architectures:
  - Foundations: Python, NumPy, Pandas, Matplotlib, Statistics, Linear Algebra
  - Classical ML: Regression, Classification, Clustering, Random Forest, XGBoost, Scikit-learn
  - Deep Learning: Neural Networks, CNNs, RNNs, Transformers, Computer Vision, NLP
  - Modern Generative AI: LLMs, Prompt Engineering, Embeddings, Vector Databases, RAG, Fine-Tuning, AI Agents, LLM APIs, and MLOps

### 6. CS Fundamentals Tracker
- Dedicated modules for computer science degree core subjects:
  - **OOP**, **DBMS**, **Operating Systems**, **Computer Networks**, **Computer Architecture**, **Software Engineering**, **SQL**, and **System Design**.
- 5-stage progress tracking for each subject: `Learn` ➔ `Make Notes` ➔ `Practice` ➔ `Revise` ➔ `Interview Questions`.

### 7. Communication & Soft Skills
- Preparation for non-technical interview rounds:
  - English Speaking, Reading, Vocabulary, Pronunciation
  - Technical Explanation drills
  - Group Discussion (GD) practice
  - HR round practice & Mock Interviews

### 8. Gym & Workout Log
- **Split Logging**: Push, Pull, Legs, Chest, Back, Shoulders, Arms, Core, Cardio.
- **Metric Tracking**: Exercise name, Sets, Reps, Weight (kg), Duration (min), and session notes.
- **Daily Fitness Habits**: Steps count, Water intake, and Stretching check-ins.

### 9. Project Portfolio Tracker
- Manage personal development projects from ideation to deployment.
- Preloaded starter blueprints (Full Stack App, Spring Boot Backend, ML Pipeline, GenAI RAG App, AI Agent).
- Track project tech stack, status (`IDEA`, `IN PROGRESS`, `COMPLETED`), and completion percentage.

### 10. Internship & Job Application Pipeline
- Complete recruitment management pipeline:
  - Company name & target role
  - Application date & submission deadlines
  - Status stages: `Applied` ➔ `OA Received` ➔ `OA Completed` ➔ `Technical Interview` ➔ `HR Interview` ➔ `Offer Extended` / `Rejected`
  - Custom application notes (referral codes, recruiters, interview feedback).

### 11. Goal Setting & Milestones
- Set measurable quantitative goals (e.g. *"Solve 200 LeetCode Problems"*, *"Build 5 Projects"*, *"Maintain 30-Day Gym Consistency"*).
- Visual progress bars, target vs. current indicators, and target deadline dates.

### 12. Activity Calendar & Deep Work Statistics
- **Monthly Interactive Calendar**: Visual heat-dots mapping daily activity and study consistency.
- **Deep Work Statistics**: Weekly, monthly, and all-time study hours breakdown with completion rates.

## 🎨 Core Design Principles

- **Sleek Modern Aesthetics**: Glassmorphism cards, refined borders, and harmonious accents built on HSL/RGB design tokens.
- **Typography Hierarchy**: Powered by *Plus Jakarta Sans* (UI headings), *Outfit* (clean modern body), and *JetBrains Mono* (code & data metrics).
- **Dual-Theme Architecture**: Seamless toggle between a dark terminal workspace and an ultra-clean light mode.
- **Zero Clutter, Zero Distractions**: Responsive sidebar navigation with mobile drawer support for on-the-go tracking.

## 🛠️ Getting Started Locally

Because TechPrep OS relies purely on standard web technologies, there are **no package installations or build steps required**.

### 1. Clone the repository
```bash
git clone https://github.com/Abhinav642007/Tracker.git
cd Tracker
```

### 2. Run the application

#### Option A: Direct Open
Simply double-click [`index.html`](file:///Users/apple/Desktop/PROJECTS/MAJOR-PROJECTS/TechPrep-OS/index.html) or open it with your favorite browser:
```bash
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

#### Option B: Using a Lightweight Local Server
Using Python:
```bash
python3 -m http.server 3000
```
Or using Node `npx serve`:
```bash
npx serve .
```
Then visit `http://localhost:3000` in your browser.

## 🔒 Data Storage & Privacy

- **100% Private**: All your activity, problem logs, goals, and applications are saved locally to your device through `window.localStorage`.
- **System Reset Control**: Under the **Settings** panel, you can perform a safe clean reset of your progress data back to 0 without losing the preloaded roadmaps and habit categories.
